# UE 5.8: продолжение исследования и Фаза 0

Дата: 2026-10-06. Продолжение [основного отчёта](ai-unreal-landscape.md) после уточнения: пользователь работает на **UE 5.8**.

## Что меняет версия 5.8

- **Ветка для ≤5.7 отпадает.** Мост `HusBridge`, C++ K2-кодек и CI на четыре движка (триггер 2b, ~8 чел.-нед.) не нужны. Остаётся одна цель: эндпоинт Epic + наши тулсеты в реестре.
- **Python достаёт до графов Blueprint.** В 5.8 есть `unreal.BlueprintGraphEditor`, поэтому чтение и патч графов BP можно сделать без C++ уже в MVP. Осторожно с русским UI редактора: ноды создаём по классу и member-ссылке, а не по локализованному имени.
- **MVP целиком без компиляции C++ становится реалистичным.** C++ нужен только для авторинга AnimBP state machines, BT/StateTree, UDS и для надёжности (модальные окна, отмена).

## Что подтвердил официальный плагин Epic для Claude Code

Источник: [EpicGames/unreal-engine-skills-for-claude-code-plugin](https://github.com/EpicGames/unreal-engine-skills-for-claude-code-plugin) @a6aa73a (2026-09-17, MIT).

1. **Python-тулсеты — официальный путь.** Skill `create-toolset` прямо говорит, что Python «generally preferred». Класс `@unreal.uclass()` наследует `unreal.ToolsetDefinition`, методы помечаются `@toolset_registry.tool_call` + `@staticmethod`, обязательны аннотации типов (схема строится из них), регистрация — `unreal.ToolsetRegistry.register_toolset_class(...)` из `init_unreal.py` плагина. Сериализацию типов в JSON делает реестр. Это снимает главный риск спайка Фазы 1: content-only плагин с Python-тулсетами — штатный сценарий, а не хак.
2. **Контракт тулсета у Epic совпадает с нашим.** Ошибка — исключение, а не `bool`/строка; функции статические; документация короткая («режь всё, что выводится из сигнатуры»), тесты обязательны (`ToolCallTestCase` для Python).
3. **Skill Epic сам создаёт главный сток discovery.** Он велит агенту в начале работы вызывать `list_toolsets`, а затем `describe_toolset` на нужных тулсетах. По нашим замерам это ≈2,7k токенов на список и ≈16k на один BlueprintTools (Niagara — ≈62k). Наш пакет L0 заменяет этот шаг локальным каталогом сигнатур.
4. **Хук плагина дешёвый.** SessionStart-хук добавляет 2–3 предложения контекста (≈80 токенов) — его можно оставить.
5. **Режим tool search переключается.** `bEnableToolSearch=False` в ini регистрирует все инструменты как нативные. В Claude Code это не нужно (он сам откладывает схемы), но для клиентов без deferral это анти-паттерн: ≈160k токенов схем.
6. **Полезные консольные команды**: `ModelContextProtocol.GenerateClientConfig ClaudeCode`, `ModelContextProtocol.RefreshTools`, `ModelContextProtocol.StartServer [port]`.

## Фаза 0: живой замер на вашем редакторе

Модель в основном отчёте посчитана без живого редактора (±30%). Первый шаг — заменить её реальными цифрами с вашей машины.

### Шаг 1. Зонд обнаружения (готов)

Скрипт [`tools/ue58-probe/probe.py`](../../tools/ue58-probe/probe.py): Python 3.9+, без зависимостей, только чтение. Он вызывает лишь мета-инструменты (`tools/list`, `list_toolsets`, `describe_toolset`) и не трогает состояние редактора.

```
# в каталоге проекта, при запущенном редакторе с плагином ModelContextProtocol
python <путь>/tools/ue58-probe/probe.py --url http://127.0.0.1:8000/mcp
```

Результат — в `Saved/hus/probe/`:
- `summary.json` — только числа: сколько стоит каждый тулсет, доля `outputSchema`, какие ответы длиннее 50 000 символов (Claude Code уводит их в файл), задержки. **Этот файл можно прислать.**
- `catalog.txt` — компактные сигнатуры вида `Toolset.tool(arg: type, opt?: type) -> Ret  # первое предложение описания`. Это заготовка локального каталога для пакета L0. Содержит текст Epic, поэтому остаётся только у вас.
- `raw/` — дословные ответы сервера, тоже только локально (UE EULA).

Ожидаемо по модели: все `describe_toolset` вместе — порядка сотен тысяч токенов, каталог — в разы меньше. Зонд покажет реальное сжатие на вашем наборе плагинов.

### Шаг 2. Пакет L0 (следующая работа)

Собирается из результата шага 1, без кода в редакторе:
- skill `unreal-lean` (≤1,5k токенов): «не вызывай `list_toolsets`/`describe_toolset`, ищи сигнатуру в `Saved/hus/probe/catalog.txt` через grep», правила форматов и безопасности;
- блок в `CLAUDE.md` (~60 токенов);
- хуки Claude Code: PostToolUse разворачивает `returnValue`, превращает строки в TSV, а base64-скриншоты сохраняет в JPEG 960 px на диск;
- отключение «Use Less CPU when in Background» (~333 мс → 8 мс на команду).

### Шаг 3. Сравнительный замер

Одни и те же задачи (найти источники света, массово поменять свойство, прочитать/изменить Blueprint, материал, скриншот, «кто вызывает X») в двух конфигурациях: Epic по умолчанию и Epic + L0. Метрика — токены и запросы на успешную задачу из `/usage` или stream-json. Гейт Фазы 0: L0 дешевле минимум в 1,8 раза. Иначе — перемерить, прежде чем писать фронт.
